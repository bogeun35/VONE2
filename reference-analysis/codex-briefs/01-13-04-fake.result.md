key findings:
- **실제 참가자의 몸체는 authored Player spawn을 만들지 않고 FakePlayer 목록에서 배정한다.** OnStart `0x181842458` -> assignPlayer `0x1818424c0`; 무작위 stable removal `0x181842963..9ce`; 참가자 index `0x181842a8d`, colour `0x181842a97`, manual mode=1 `0x181842aa3`. 참가자 identity와 몸체를 구분해야 한다. 일반 늦은 참가 생성은 별도 `ActorFactoryComponent.CreateJoinedPlayer 0x1816a4b50` 경로이며, 이번 구현은 이 전체 관계를 검증하지 않았다.
- **FakePlayer는 움직이는 충돌 몸체다.** InitCollision `0x18183e30f`에서 충돌을 만들고 attribute=6을 저장한다(`0x18183e319`). OnUpdate는 aiProc -> manualProc -> actionProc 순서다(`0x18183e50a/51b/53b`). 모방 AI는 참가자 index를 RNG로 골라 쓴다(`startImitate 0x18183f038`). 정확한 pushback/grounded 물리는 미이식이다.
- **manual과 player는 다르다.** IsManual `0x181840e20`은 mode==1, IsPlayer `0x181840e00`은 fadeState>0. 정답 결과는 cage event35, fake event1(param=1), info.FakePlayer ref 삭제를 한다(`0x181844fa3..fee`). fake의 event 수신부가 manual만 fadeState=1과 collision attribute=1로 드러낸다(`0x181840b87..bbc`). 성공 결과 경로에는 새로운 Player actor 생성이 없다.
- **지정 두 actor가 추가 actor들을 자동 생성한다.** FakePlayer.Creator는 FakeCage를 생성(`0x18183e1b5` -> `0x18183c170`), FakeTimer.showCursor는 참가자마다 FakeCursor를 생성(`0x181843741` -> `0x18183cd80`). 기존 source 모듈에는 두 구현이 없다. AGENTS.md의 “If a module you need from another task does not exist yet, say so in the result note instead of writing it yourself.” 규칙에 따라 actor type을 추가 구현하지 않았다.
- **2..8인 타이머는 10/10/11/11/12/12/13초다.** datas[0] FP 표 및 fallback `ParseParameter 0x181841e29/0x181841f0b..fb2`. 추가 manual의 int32 표는 `[2,2,1,1,0,0,0]`이나 `Find 0x181786950`의 비영 fallback으로 실제 결과는 **2/2/1/1/1/1/1**이다. 6..8인을 0개로 구현하면 틀린다.
- **History는 가짜 행동이 아닌 참가자 입력이다.** `Frame.GetGamePlayerInput 0x181843ccf`, left/right/jump bit 1/2/4 `0x181843cdc..cff`. 4개 sample×8개 slot, 4 sample을 처음부터 분모에 포함하며 `count*4`로 FP 나눈다(`0x181843e80..edc`).
- **페이드 1초는 60Hz에서 61틱이다.** 초기 raw65536 `0x18183e234`, 틱마다 DeltaTime raw 차감 `0x181840a65`, <=0 종료 `0x181840a8f..ab6`. 60틱은 raw16이 남는다.
- **최종 성공은 단순 열쇠 활성화가 아니다.** manual list의 IsClear bit3 검사 `0x181843a8b`, Stage flag bit11 및 SE15 `0x181843240..24c`. 오답은 Stage flag bit10 `0x181844e9a`. 이 연동은 미이식이다.
