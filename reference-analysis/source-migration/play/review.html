2~8인 자동 검수

검수 기록 불러오는 중

첫 라운드 출발 지점에서 실제 입력을 반복한 검사와, 장치 앞에 캐릭터를 배치한 개별 동작 검사입니다. 실제 입력 검사는 20초 동안 진행했습니다.

추가 검수: 출발 지점부터 실제 키 입력만으로 2~8인 전원의 열쇠 획득·문 입장·클리어를 확인했습니다. 8인 기록은 약 3분 20초이며 V키로 4배속 재생할 수 있습니다. 게임에서 T키로 8인 입력 재생을 볼 수 있습니다. 캐릭터 좌표나 열쇠 상태를 강제로 바꾸지 않았습니다.

현재 게임성 판단

  • 동료 위에 올라가 길을 여는 역할 분담은 협동 요소가 됩니다. 모두 같은 방향으로 걷고 점프하는 것만으로는 첫 계단을 넘지 못했습니다.
  • 6~8인에서는 탑 맨 위 점프와 아래 동료 점프의 시차가 필요했습니다. 이 해석된 물리가 원본과 일치하는지, 첫 라운드로서 너무 까다롭지는 않은지 추가 확인이 필요합니다.
  • 스위치 눌림, 5초 카운트다운, 스프링 발동 표시를 보강했습니다. 작동 타이밍을 눈으로 맞출 수 있습니다.
  • 8명이 탑을 쌓고 동시에 이동하면 위쪽 캐릭터에 이동량이 누적됩니다. 원본과 같은 동작인지 추가 비교가 필요합니다.

현재 원본 첫 라운드의 2~8인 기능 검수는 통과했습니다. 원본 물리와 열쇠 전달 방식의 일치, 온라인 전체 경로, 실제 사람의 재미 평가는 아직 검수 중입니다. 자동 클리어를 게임성 검수 완료로 계산하지 않습니다.

검수 음악은 껐습니다. 배경음악은 새로 만든 40초 오리지널 곡이며 M키로 끌 수 있습니다.
